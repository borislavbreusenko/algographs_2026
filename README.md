# Домашнее задание 1

## Идея решения

Сначала разрушаются циклы длины два: выбирается вершина с максимальной суммой обратных степеней её соседей в графе двухциклов. Затем вершины удаляются жадно по произведению входящей и исходящей степеней. Листья исключаются из поиска, а компоненты сильной связности периодически пересчитываются, чтобы обрабатывать оставшиеся циклы независимо.

Далее чередуются пять стратегий: проход вставок в топологический порядок, возврат одной вершины в reverse-delete, проход одиночных обменов, поиск замены пары удалённых вершин не более чем одной вершиной и тройки — не более чем двумя. Когда для замены остаётся удалить одну вершину, кандидаты пересекаются с найденными циклами. Для тройки циклические компоненты решаются отдельно; если их больше двух, обмен невозможен. Каждый цикл содержит 100 вызовов: сначала по 20 на стратегию, затем пропорционально накопленному уменьшению ответа, но минимум по 5 подряд. Reverse-delete сохраняет очередь кандидатов. Изначально я придумал просто пачку эвристик и вызывал их по очереди, но в каких-то случаях одна эвристика могла выполняться долго, поэтому я сделал чередующуюся последовательность эвристик, а чтобы использовать те которые дают наибольший результат, сделал адаптивную частоту. Лимит 570 секунд проверяется и внутри стратегий; по времени или сигналу возвращается лучший сохранённый ответ.

##
Папка `solution` содержит код решения, папка `task2` содержит граф для части 2 задания.

## Сборка

Из корня репозитория, C++23:

```bash
clang++ -std=c++23 -O3 -DNDEBUG -march=native -Wall -Werror -Wsign-compare solution/solution.cpp -o ./dfvs
```

## Запуск

```bash
./dfvs
```

Пример ввода из задания:

```text
4 5 0
2
3
1 4
3
```

Вывод для этого примера:

```text
3
```

Альтернативно можно передать файл с данными и указать файл для ответа:

```bash
./dfvs < task2/graph.gr > answer.ans
```

Здесь `<` подаёт содержимое `task2/graph.gr` в `stdin`, а `>` записывает `stdout` в `answer.ans`.
